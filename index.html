      How to practise a question

      1. Read the question. Close the docs.
      2. Answer out loud in under 60 seconds, with one example from your own work or project.
      3. Check the docs link. Fix what you got wrong, then say it again.
      4. Mark Can explain when you get it right with notes, Confident only when you can do it cold.

      One or two questions in the 10-minute side-skill slot each weekday. Marking one also ticks "STAR / design / project" on today's log.
